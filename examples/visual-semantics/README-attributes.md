# Exemple K4 : configuration synthétique (non activée)

Le fichier `qualified-attributes.example.json` est un exercice de validation pour le compilateur visuel. **Il ne doit pas être copié tel quel dans `config/visual-attributes.json` sur un corpus réel.** Les `relationId`, `dimension` et valeurs sont fictifs ; la preuve scientifique, les politiques et la légalité de publication ne s'en déduisent pas.

La configuration active reste vide après installation. Pour une vraie règle, partir des identifiants et unités effectivement observés dans un état Kristal autorisé, et documenter le contrôle humain des bornes et valeurs avant de modifier le registre local.
