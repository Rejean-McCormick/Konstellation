# Konstellation / diK — navigation of semantic views

**DOCUMENTED only, 24 November 2026.** Konstellation navigates a Kristal
collection and its authorized read projections; it does not choose an active
canonical revision or authorize GitHub publication.

For v11 opted-in sources, a local KQ/KP has identity only when paired with
its `namespace_id`. Two Kristals may contain `KQ1001` without sharing a
referent. Wikidata Q/P is a separate reviewed external mapping; lexical
labels and fallbacks must be displayed as presentation/provenance, not as
identity merge keys.

The diK decision profile `/0.2` adds a graph SHA to four previous input
hashes, but `SINGLE_DECLARED_DERIVED_VIEW` or
`OPERATOR_PINNED_DERIVED_VIEW` still means **non-authoritative browsing**.
An ambiguous multirevision source remains unselected. Keep the historical
v9/v10 readers and isolated v11 preview intact. There is no automatic
network route, migration, write or activation in this note.
