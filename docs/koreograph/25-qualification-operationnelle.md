# Qualification opérationnelle automatisée — tranche v0.4

Cette extension ajoute des outils, sans changer les moteurs, composants, droits, dépendances ni données du dépôt. Elle s'appuie sur l'instance **locale déjà démarrée** du propriétaire et son catalogue explicitement configuré. Le profil `/v11` isolé n'est pas couvert. Les cinq démonstrations synthétiques et leurs 45 contrôles Windows v0.3.4 restent des preuves distinctes.

## Exécution

Prérequis : Node >=24.15, dépendances existantes du projet, Python Playwright et ses navigateurs installés. Démarrer Konstellation normalement, par exemple avec son lanceur habituel, puis depuis la racine dans un autre terminal :

```powershell
$Out = Join-Path (Get-Location).Path "artifacts\koreograph-real-$(Get-Date -Format yyyyMMdd_HHmmss)"
node scripts/koreograph-qualify-real.mjs --catalogue-prive --out $Out
python scripts/koreograph-real-ui.py --catalogue-prive --report (Join-Path $Out 'ui-chromium.json')
```

La première commande utilise uniquement le serveur `http://127.0.0.1:4321` par défaut. Une autre adresse HTTP sur `127.0.0.1` avec port peut être fournie par `--base`. Les redirections HTTP sont refusées. Aucun balayage du système de fichiers, démarrage/arrêt de serveur, changement de profil, de droits, écriture canonique, commit ou publication. Ne pas exécuter sur une instance ou un compte non autorisé. Si l'instance exige un jeton, le CLI Node accepte `KOREOGRAPH_QUALIFICATION_TOKEN` dans l'environnement du processus ; ne pas le transmettre dans les rapports. Le script UI exige une session locale non interactive (pas d'automatisation du login). Le jeton optionnel n'est pas transmis au processus de rendu Python.

## Campagne bornée

- Inventaire : entrées disponibles de `/api/kristals`, sélection explicite par `--catalogue-prive`. Le bootstrap confirme `synthetic:false`, le Kristal choisi, la disponibilité Koreograph et un principal non anonyme. Les entrées indisponibles sont dénombrées, pas ouvertes.
- Pour chaque politique et perspective échantillonnée : requête, plan et projections annoncées par le serveur ; validation par les contrats Ajv existants. Contrôle des entités retournées par rapport au bootstrap filtré (pas une preuve complète des assertions ou des ACL). Les parcours Auto, Script et Kapture compilés utilisent les voisins réellement reçus ; un faux contexte est refusé par le compilateur. La capture compilée n'est pas un test des interactions Kapture dans Svelte.
- Vérification négative ponctuelle si deux politiques exposent des ensembles différents : demander une entité visible sous l'autre politique et une entité absente dans la constellation sous la politique courante ; attendre deux HTTP 404. Aucun changement de politique sur le serveur. Ce test ne prouve pas l'absence de toute fuite et peut être non applicable.
- Reproductibilité sur les mêmes DTO, pas sur deux versions de la source. Les politiques et recettes non couvertes à cause des plafonds sont signalées. Une seule perspective par défaut (première non vide), deux politiques et deux recettes spécialisées, jusqu'à 12 Kristals et 48 cas au total. `--max-kristals`, `--max-policies`, `--max-lenses`, `--max-recipes`, `--max-cases` ajustent ces plafonds (maximums respectifs 24,5,6,8,120). `--only` sélectionne une liste d'identifiants de Kristals séparés par des virgules. `--ratio 1:1` et `--theme signature` sont les défauts ; autres valeurs possibles, une combinaison par exécution. `--browsers chromium,firefox,webkit` par défaut. `--api-only` omet les navigateurs et maintient le résultat en revue. `--python` choisit l'exécutable Python.
- Rendu : contrôleur SVG existant sans assouplissement ; lecture HTML autonome hors réseau, commandes clavier, lecture/pause, chapitres, transcription et mouvement réduit pour le spécialisé. Le SVG et le HTML sont des fichiers temporaires privés, supprimés normalement même en cas d'erreur ; un arrêt forcé du processus peut laisser des fichiers `kg-real-*` dans le dossier temporaire système. Aucun export réel conservé dans le rapport.
- UI live : un échantillon spécialisé, trouvé parmi les six premiers Kristals disponibles (`--max-sources` ajustable), sur le navigateur choisi. Lecture/pause, chapitres si disponibles, clavier, huit thèmes, trois ratios, mouvement réduit, refus avant consentement, cinq exports et reçus SHA-256 (signature PNG comprise), révocation du dernier Blob et retrait de l'ancien SVG après changement de politique ou, à défaut, de Kristal. Les liens privés sont téléchargés dans le contexte navigateur temporaire de Playwright, vérifiés puis supprimés immédiatement ; une interruption forcée peut laisser des fichiers temporaires. La révocation est observée via un instrument de test en mémoire, sans modifier la CSP. Aucune trace, capture d'écran ou vidéo n'est sauvegardée. Ce smoke ne qualifie ni toute l'interface, ni la capture orbitale interactive, ni les transitions inter-familles. Il bloque les requêtes externes côté navigateur. L'instance doit être locale et autorisée ; le script ne modifie pas sa configuration.

## Résultats

`qualification.json` est écrit progressivement. Les identifiants de cas, politiques, perspectives et Kristals sont des ordinaux propres à la campagne ; aucun libellé, identifiant métier, jeton, DTO, chemin de source, ni texte d'erreur arbitraire n'est écrit. Les empreintes de sortie sont conservées pour l'intégrité ; garder les rapports privés et vérifier avant de partager. Les résultats UI sont distincts. `pass` = contrôles échantillonnés réussis, `review` = avertissement, projection partielle, limite ou couverture manquante, `fail` = échec. Codes 0, 2, 1. Aucun statut n'est une certification, une permission de publication ou une validation du contenu canonique.

Validation de développement : quatre tests de l'orchestrateur avec transport fictif et validation injectée, 32 tests existants, deux SVG + leurs lecteurs autonomes Chromium 144 (spécialisé standard/réduit, orbital standard). La syntaxe Python est vérifiée. L'API réelle, les contrats Ajv en exécution, le smoke Svelte et Firefox/WebKit sur données réelles restent à éprouver sur le poste du propriétaire. L'accessibilité exhaustive, les exports vidéo et les transitions inter-familles restent des chantiers séparés.

**Correctif de clôture v0.4.1.** Les libellés et légendes orbitaux utilisent le même pas typographique de 1,65 que les cartes spécialisées ; les coordonnées et la loi de mouvement restent inchangées. Le test UI distingue les étapes du lecteur et des exports sans enregistrer les données métier. Une exception d’exécution du navigateur peut être retentée une fois avec conservation de son type et de sa phase ; les défauts de rendu observés ne sont pas effacés par une relance. Les résultats partiels restent `review`.
