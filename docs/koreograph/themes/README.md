# Bibliothèque Theme 0.1

Huit presets documentaires déclaratifs, validables avec le [schéma Theme](../schemas/theme.schema.json). Le mode par défaut peut être changé par la demande de production. Couleur de marque `#1E6864` dans tous les presets ; aucun asset, aucun script. Les palettes par kind sont proposées et ne remplacent pas la taxonomie du DTO. La couleur seule ne suffit pas : contour, label, forme et légende sont requis. Voir [direction artistique](../15-direction-artistique-themes.md). Les contrastes des tokens de base sont contrôlés par le script documentaire ; la lisibilité du rendu complet reste à tester.

- [Signature](signature.json) — mono
- [Paper](paper.json) — mono
- [Graphite](graphite.json) — mono
- [Ink](ink.json) — mono
- [Spectrum](spectrum.json) — by-kind
- [Atlas](atlas.json) — by-kind
- [Blueprint](blueprint.json) — mono
- [Editorial](editorial.json) — by-kind
